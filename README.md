This repository contains a comprehensive EDA workflow focused on analyzing a movie revenue datasets using the following 9-step workflow:

1.	Introduction
2.	Problem Statement
3.	Installing & Importing Libraries
4.	Data Acquisition

7.	Data Post-profiling
8.	Exploratory Data Analysis
9.	Summarization
________________________________________
📘 Project Overview

The modern film industry generates billions in revenue each year. Understanding the factors that influence movie success can help studios and analysts make informed decisions.
In this project, we explore a movie dataset through:
•	Detailed Exploratory Data Analysis (EDA)
•	Data Cleaning
•	Data Visualization
•	Feature engineering
•	Extracting actionable business insights
•	Automated data profiling for univariate analysis using ‘y-data profiling’
________________________________________

🧰 Tech Stack & Libraries

•	Python 3
•	NumPy
•	Pandas
•	Matplotlib & Seaborn
•	Y-data profiling
