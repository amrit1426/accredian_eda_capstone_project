# An Exploratory Data Analysis on a Movie Revenue Dataset

This repository contains a comprehensive EDA workflow focused on analyzing a movie revenue dataset using the following 9-step workflow:

1. Introduction
2. Problem Statement
3. Installing & Importing Libraries
4. Data Acquisition
5. Data Pre-profiling
6. Data Pre-processing
7. Data Post-profiling
8. Exploratory Data Analysis
9. Summarization

## Project Overview

The modern film industry generates billions in revenue each year. Understanding the factors that influence movie success can help studios and analysts make informed decisions. In this project, we explore a movie dataset through:

- Detailed Exploratory Data Analysis (EDA)
- Data Cleaning
- Data Visualization
- Feature engineering
- Extracting actionable business insights
- Automated data profiling for univariate analysis using y-data profiling

## Tech Stack & Libraries

- Python 3
- NumPy
- Pandas
- Matplotlib & Seaborn
- Y-data profiling
- Jupyter Notebook

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/amrit1426/accredian_eda_capstone_project.git
   ```
2. Install required packages:
   ```
   pip install -r requirements.txt
   ```
3. Launch the notebook:
   ```
   jupyter notebook
   ```
4. Open the ipynb file named:
   `abaruah289@gmail.com.ipynb`
